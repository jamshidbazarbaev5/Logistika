# Документация компонента Dashboard2

## Обзор
Dashboard2 - это комплексная панель аналитики, которая отображает различные метрики и визуализации, связанные с заявками, транзакциями и продуктами в логистической системе.

## Источники данных

### 1. Данные заявок
- **Эндпоинт**: `https://cargo-calc.uz/api/v1/application/`
- **Получаемые данные**: 
  - Активные заявки (`status=active`)
  - Завершенные заявки (`status=completed`)
  - Включает информацию о брутто, нетто весах и данных о фирмах
  - Поддерживается пагинация для больших наборов данных

### 2. Данные транзакций
- **Эндпоинт**: `https://cargo-calc.uz/api/v1/transactions/`
- **Назначение**: Отслеживание движения и количества продуктов
- **Связанные данные**: Связь с заявками через `application_id`

### 3. Данные платежей
- **Эндпоинт**: `https://cargo-calc.uz/api/v1/application/pay/`
- **Назначение**: Отслеживание финансовых транзакций
- **Фильтрация**: Только для завершенных заявок

### 4. Данные продуктов
- **Эндпоинт**: `https://cargo-calc.uz/api/v1/items/product/`
- **Назначение**: Основной список всех продуктов в системе

### 5. Данные типов транспорта
- **Эндпоинт**: `https://cargo-calc.uz/api/v1/transport/type/`
- **Назначение**: Информация о различных типах используемого транспорта

### 6. Данные фирм
- **Эндпоинт**: `https://cargo-calc.uz/api/v1/firms/firm/`
- **Функция поиска**: Поддерживает поиск фирм по названию
- **Детали**: Включает название фирмы и ИНН

## Основные функции

### 1. Отображение статистики
- Общее количество заявок
- Количество активных заявок
- Количество завершенных заявок
- Общий доход
- Общий вес брутто
- Общий вес нетто

### 2. Возможности фильтрации
- По диапазону дат (dateFrom, dateTo)
- По фирме
- По продукту

### 3. Визуализации
1. **График статуса заявок**
   - Показывает распределение активных и завершенных заявок
   - Использует компонент PieChart

2. **График распределения продуктов**
   - Показывает топ-15 продуктов по количеству
   - Интерактивная легенда с функцией прокрутки
   - Визуализация процентного распределения

3. **Таблица продуктов**
   - Постраничное отображение продуктов
   - Показывает название продукта, количество, число заявок
   - Сортировка по названию или количеству

### 4. Обновления в реальном времени
- Данные обновляются при:
  - Изменении диапазона дат
  - Изменении выбранной фирмы
  - Изменении выбранного продукта

## Управление состоянием

### Основные переменные состояния
1. `applications`: Хранит данные всех заявок
2. `transactions`: Хранит историю транзакций
3. `payments`: Хранит информацию о платежах
4. `products`: Хранит каталог продуктов
5. `selectedFirm`: Текущая выбранная фирма
6. `dateFrom` и `dateTo`: Фильтры диапазона дат

### Вычисляемые значения
1. `applicationStats`: Рассчитывает статистику на основе заявок
2. `totalRevenue`: Вычисляется из данных о платежах
3. `totalBrutto` и `totalNetto`: Рассчитывается из весов заявок
4. `firmProductData`: Обрабатывает данные о распределении продуктов

## Оптимизация производительности

1. **Пагинация**
   - Таблица продуктов использует клиентскую пагинацию
   - API поддерживает серверную пагинацию

2. **Кэширование данных**
   - Мемоизированные вычисления с использованием useMemo
   - Предотвращает ненужные перерендеры

3. **Состояния загрузки**
   - Индикатор загрузки во время получения данных
   - Скелетная загрузка для лучшего UX

## Обработка ошибок
- Логирование ошибок API в консоль
- Управление состоянием ошибок для неудачных запросов
- Плавная деградация функций при недоступности данных

## Интернационализация
- Использует i18n для переводов
- Поддерживает несколько языков через файлы переводов
- Форматирование чисел в соответствии с локалью
